# 明日方舟线索赠送策略分析

基于博弈论和蒙特卡洛仿真，研究明日方舟基建系统中**线索赠送策略**对信用点收益的影响。

---

## 研究问题

> 在一个由 N 名玩家组成的互动群体中，玩家采取何种线索赠送策略，能最大化个人/群体的长期每日信用点收益？该策略是否构成纳什均衡？

---

## 核心结论

**最优策略 S\***：赠出所有重复线索（+20信用/条），保留唯一线索，集齐立即触发交流。

S\* 是**严格占优策略**——在任何对手策略下，偏离 S\* 都会让自己受损：

| 策略 | 个人 cr/天（N=10）| 与 S\* 差距 |
|------|:---:|:---:|
| S\* 定向赠送（Optimal_Targeted）| **~230**（群体最优）| +0.9% |
| **S\*（最优）** | **~227** | — |
| 利他安全（Altruistic_Safe）| ~228 | +0.3% |
| 利他（见啥送啥）| ~226 | -0.7% |
| 阈值-8 | ~182 | -20% |
| 阈值-10（满仓才送）| ~178 | -22% |
| 半合作-7号线索 | ~100 | -56% |
| 利己（从不赠送）| ~83 | -63% |

> 注：信用点/天基于典型配置（2×E2-5★ + Lv.3会客室，λ≈3.0条/天，Beta-Binomial访问模型）

## 仿真模型（v5）

### 线索生成（双来源）
- **4AM 固定**：每天产出1条线索
- **干员搜集**：泊松过程，速率 $\lambda_{\text{op}} = \frac{24}{20}(1 + b_{\text{op}} + 0.15)$
- 两种来源分布相同，共享10条上限；容量满时生成进度**暂停**（不丢失）

### 线索消失机制
| 途径 | 说明 |
|------|------|
| 触发交流 | 消耗自持各1条（优先用自己的，不够用收到的）|
| 赠送 | 只能赠自己找到的线索，消耗1条，+20信用 |
| 主动删除 | 利己策略使用，消耗，+5信用 |
| 收到的过期 | 收到的线索**10天有效期**，到期自动消失 |

### 策略空间

| 策略 | 行为描述 |
|------|---------|
| `Altruistic` | 赠出所有线索，唯一例外：凑齐7种的最后那条保留 |
| `Altruistic_Safe` | 同上，但当恰好缺2种且已持有其一时，也不赠出 |
| `Selfish` | 从不赠送；满时删除重复（+5/条）|
| `Selfish_Type7` | 只赠7号线索的重复份；其余类型同Selfish删除逻辑 |
| `Optimal_S*` | 有重复才赠出（随机好友）|
| `Optimal_Targeted` | 有重复才赠出（优先缺该类型的好友）|
| `Threshold_8` | 自持总量≥8且有重复才赠出 |
| `Threshold_10` | 满仓（≥10）才赠出；若新线索非重复则赠任意重复线索 |

## 快速运行

```bash
# 需要 Python 3.9+ 和 numpy
pip install numpy

# 运行全部实验（约15-25分钟，8策略×7实验）
cd simulation
python3 -u run_experiments.py
```

### 主要实验

| 实验 | 内容 |
|------|------|
| E1 | 单人基准（无好友，各策略对比）|
| E2 | 群体规模效应（N=1~50，全S*）|
| E3 | 同质策略对比（N=10，各策略均等）|
| E4 | 博弈均衡分析（1人偏离S*群体）|
| E5 | 商店容量敏感性 |
| E6 | 线索概率分布效应（均匀 vs 非均匀）|
| E7 | λ 敏感性（干员加成对收益的影响）|
