> - 双来源线索生成：每日4AM固定+1条 + 干员泊松生成（典型 λ_total ≈ 3.0/天）

## 1. 解析结果（主要结论不变）

### 1.1 优惠收集问题（Coupon Collector）

**均匀分布**（$p_k = 1/7$）：
$$\mathbb{E}[\text{集线数}] = 7 \cdot H_7 \approx 18.15, \quad \mathbb{E}[\text{周期}] = 18.15 / 3.0 \approx 6.1 \text{ 天}$$
$$\mathbb{E}[\text{重复线索/周期}] = 11.15$$

**非均匀分布**（$p_7=16/70$，修正后，Monte Carlo n=200,000）：
$$\mathbb{E}[\text{集线数}] \approx 20.0, \quad \mathbb{E}[\text{周期}] \approx 6.7 \text{ 天（+10\%）}$$

> **注**：v2 非均匀分布 (p₇=0.4) 结果严重偏差。修正后惩罚从 +35% 降至约 +10%。

### 1.2 重复线索的三种处置方式

| 处置 | 自身收益 | 好友收益 | 对自身交流的影响 |
|------|:---:|:---:|:---:|
| 赠出（S*）| +20 信用点 | 线索 + 15/10/5 | 无（仍有1条用于交流）|
| 删除（s=1）| +5 信用点 | 无 | 无 |
| 持有 | 0 | 无 | 无（但占库存位）|

**结论**：赠出 > 删除 > 持有。

### 1.3 赠出唯一线索的代价（均匀分布，λ≈3.0/天）

- 期望额外等待：1/p_k = 7 次产出 ≈ 2.33 天
- 延误代价 ≈ **80 信用点**（λ 出现在分子分母互消，结果对 λ 不敏感）
- 赠出获得：+20 信用点
- **净损失：约 -60 信用点**（与 v2 约 -61 信用点基本相同）

## 2. 仿真结果（v3，Monte Carlo，N_RUNS=30，N_DAYS=365，λ≈3.0/天）

|------|:---:|:---:|:---:|
| 利他 (s=0) | 0.02 | 0 | 1083.5 |
| **利己 (s=1)** | **42.01** | 0.155 | 0 |
| S* | 0.02 | 0 | 1083.5 |
| S* 定向 | 0.02 | 0 | 1083.5 |
| 阈值-8 | 0.02 | 0 | 1083.5 |

> **注**：s=1（利己）在单人时通过删除重复（+5×删除数）正常运作。
> 其他策略无法赠送，又不删除，线索溢出至队列约 1084 条/年（λ≈3×365=1095条 − 10满容量）。
> 注意 s=1 的日收益从 v2 的 16.40 上升到 42.01，因为 λ 提高后交流频率和删除次数均增加。

## 4. 综合结论

### 4.1 策略建议（个人视角）

$$\sigma^* = \text{\"赠出所有重复线索，保留唯一线索，集齐立即触发交流\"}$$

在有好友的情况下，这是个人和群体的共同最优。高 λ 下利他与 S* 差距极小，但利己策略仍显著落后。

### 4.2 纳什均衡与社会最优一致

S* 是（近似）纳什均衡，同时也是群体最优。

$$\text{PoA（阈值-8 vs S*）} = \frac{2403.76}{2020.24} \approx 1.19$$

### 4.3 新发现：定向赠送（OPTIMAL_TARGETED）

定向赠送在高 λ 环境下不优于随机赠送。原因：线索充裕时几乎所有好友已拥有所有类型，定向赠送退化为随机赠送，额外搜索开销无实际获益。定向赠送的优势可能仅在低 λ 或小 N 场景下体现。

### 4.4 关键数值摘要（N=10，visits=2，均匀，商店≥400）

| 来源 | 信用点/天（S*，N=10）|
|------|:---:|
| 线索交流（210 × 0.420/天）| ~88.2 |
| 赠出重复（~3.2/天 × 20）| ~64.0 |
| 接收线索奖励（约首3条）| ~30.0 |
| 访问好友交流（2次 × 30）| ~60.0 |
| 被好友访问（10次/周 × 30/7）| ~42.9 |
| **合计（理论）** | **~285** |
| **仿真实测** | **250.90** |

> 理论值约 285，实测 250.90，差距来自被访问上限（10次/周）与访问时机的不完全重合。
